Confidentialité

Objet de cette politique

Pulse Média utilise les informations que vous nous adressez par e-mail pour répondre à vos demandes et échanger sur votre projet.

Informations recueillies

La page Contact vous permet de préparer un e-mail contenant votre nom, votre entreprise, votre adresse e-mail, la prestation souhaitée et votre message.

Fonctionnement du formulaire

Sur cette version hébergée par GitHub Pages, la saisie n’est pas transmise à un serveur Pulse Média. Le bouton ouvre votre application de messagerie avec un e-mail prérempli. Vous décidez de l’envoyer ou non. La réception dépend de votre fournisseur de messagerie.

Finalité et droits

Les informations volontairement envoyées sont utilisées uniquement pour répondre à votre demande. Pour demander leur consultation, leur rectification ou leur suppression, écrivez à pulse.instacontact@gmail.com.

Hébergement et liens

Le site statique est hébergé sur GitHub Pages. GitHub peut traiter certaines données techniques, notamment les adresses IP des visiteurs, conformément à sa politique de confidentialité. Les liens vers LinkedIn ouvrent une plateforme tierce.
